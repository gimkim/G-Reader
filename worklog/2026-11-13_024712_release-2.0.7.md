# Fast Reader/Viewer 2.0.7

## Scope

- User requested a new GitHub release of the accumulated Manhwa and display fixes.
- Version 2.0.7; assembly/file/MSIX version 2.0.7.0.
- Includes segmented Manhwa reading, configurable 1–100% width (50% default),
  remembered sections, toolbar controls, and responsive layout/state handling.
- Includes bounded staged GPU output for all JPEG/thumbnail/zoom/resize paths,
  corrected rotated BGRA dimensions, and uncached transient Manhwa presentation.
- Fixes the normal-mode blank-screen recovery identified in the last session:
  release the old flip chain and asynchronously ClearState/Flush its OLD D3D
  device before creating a new chain on that HWND. A retained old texture/device
  lease must not keep the old HWND association alive. D3D multithread protection
  and per-device serialization keep this work safe and off the UI thread.
- Fixes cached JPEG previews remaining indefinitely by promoting both visible
  pages to final quality with cancellation and source/context checks.
- The previous Computer Use session was stopped by the user's physical Escape
  key before a live-reader restart. This release session performs no UI actions.

## Evidence and validation

- Previous feature/crop/native evidence is documented in the three Manhwa
  worklogs dated 2026-11-12; these remain historical records of local builds.
- GPU registration AV/hang was proved by prior dumps; the later normal-mode log
  begins with EndDraw failure followed by CreateSwapChainForHwnd AccessDenied.
  That later log alone does not establish its original GPU-loss trigger.
- Native recovery baseline reproduced the stuck old chain. ClearState/Flush on
  the old device allowed immediate recovery, as documented by Microsoft:
  https://learn.microsoft.com/en-us/windows/win32/api/d3d11/nf-d3d11-id3d11devicecontext-flush
- Re-ran 20 forced GPU generation resets after the version bump: all passed,
  including retained old frames/device leases and bound backbuffer views.
- Two reader windows recovered on the shared device. Blocking background flush
  for 400 ms left the UI timer running (12 ticks); UI teardown took at most 1 ms.
- Re-ran actual NAS normal-reading integration after the version bump: 160
  assertions across 42 seeks, three image folders, RTL dual-page layouts,
  thumbnail/full-view and Manhwa/normal transitions. All reached final quality;
  device generation/recovery counts remained zero. Settings JSON unchanged.
- Prior native GPU tests covered all rotations, alpha, generic resize, thumbnail,
  zoom, and 168 real late-page crops with zero CUDA-D3D registration calls.
- Prior transient native stress: 500 frames / 3,271 assertions with stable cache
  ownership. Prior Manhwa layout/state/settings tests are in the feature logs.
- Release build passed with 0 warnings/errors; git diff --check passed.
- No complete foreground-reader UI verification, Store installation or Partner
  Center submission is claimed. MSIX is unsigned for Store upload.
